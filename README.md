# Crochet Pattern Studio — Pro Starter

Static responsive website for GitHub Pages. Includes a homepage, searchable/filterable pattern cards, stitch calculator, three standalone project guides, About/Contact/Privacy pages, basic SEO metadata, robots.txt and sitemap.xml.

## Upload update to GitHub
1. Open `snd3ndi-crypto/crochet-pattern-studio`.
2. Click **Add file → Upload files**.
3. Upload the contents of this folder, preserving the `patterns/` folder.
4. Click **Commit changes**.
5. Wait a few minutes and refresh https://snd3ndi-crypto.github.io/crochet-pattern-studio/

Keep GitHub Pages configured for `main` and `/(root)`.
